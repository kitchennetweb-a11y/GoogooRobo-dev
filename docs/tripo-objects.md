# Tripo object list (draft, 2026-10-21)

Rule: build in 3D only what the child touches in the scene. Every object is a vocab word (or the room's anchor), so tapping it teaches the word. The other ~150 words stay as flat pictures on cards and on Googoo's face.

Style for every prop: same look as Googoo (soft rounded toy style, matte, pastel, chunky shapes, no text or logos). Props about 5-10k polygons, GLB, private. Generate in Parts only for things that move (lamp switch, toy box lid, doors).
